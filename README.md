# Sistema de Reportes Institucionales

## Descripción

Sistema web que permitirá a los estudiantes de una institución
registrar reportes sobre diferentes problemas que se presenten
dentro de la institución.

Los estudiantes deberán identificarse mediante su número de control
antes de poder realizar un reporte.

El sistema también permitirá visualizar los reportes registrados
y conocer su estado.

## Objetivo

Desarrollar una aplicación web que permita registrar, visualizar
y administrar reportes realizados por estudiantes dentro de una
institución.

## Usuarios

El sistema contará inicialmente con dos tipos de usuarios:

- Estudiante
- Administrador

## Tecnologías

Para la primera versión utilizaremos:

- HTML
- CSS
- JavaScript
- Arrays para almacenar temporalmente los datos
