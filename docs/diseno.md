# Diseño del Sistema

## 1. Mapa de navegación

El sistema contará con una única pantalla de inicio de sesión.
Dependiendo de las credenciales proporcionadas, el sistema dirigirá
al usuario al panel correspondiente.

### Flujo general

```text
                         LOGIN
                           │
                           ▼
                  Validar credenciales
                           │
              ┌────────────┴────────────┐
              │                         │
              ▼                         ▼
        ESTUDIANTE                ADMINISTRADOR
              │                         │
              ▼                         ▼
      PANEL ESTUDIANTE               PANEL ADMIN
        │         │              │      │       │
        ▼         ▼              ▼      ▼       ▼
     NUEVO       VER          AGREGAR  AGREGAR  VER
    REPORTE    REPORTES      ESTUDIANTE ADMIN  REPORTES
       │                                           │
       ▼                                           ▼
    GENERAR                                  CAMBIAR ESTADO
   REPORTE                                          │
                                                    ▼
                                            REGISTRAR SOLUCIÓN
```
